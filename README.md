# FileFlow Report Exporter

FileFlow Report Exporter is a PHP console application that demonstrates the Singleton and Factory Method design patterns. It allows the same service records to be exported as either TXT or JSON files.

## Requirements

- PHP CLI
- Composer

## Setup

```bash
composer install
composer dump-autoload

php app.php txt
php app.php json
